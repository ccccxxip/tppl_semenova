# Выбор парадигмы и языка программирования

---

## Задача 1

| | |
|---|---|
| **Парадигма** | Императивная / Функциональная |
| **Язык программирования** | C++ |

**Обоснование:**
1. Императивная парадигма и C++ дают прямой контроль над памятью без задержек для большого потока данных
2. Функциональная парадигма позволяет легко проверять кадры с помощью математических функций
3. У C++ нет сборщика мусора, поэтому программа работает 24/7 без сбоев
4. Выбран C++, а не C, тк ресурсов сервера хватает, а C++ дает ООП и удобные библиотеки (OpenCV) для работы с видео

---

## Задача 2

| | |
|---|---|
| **Парадигма** | Скриптовая |
| **Язык программирования** | Python |

**Обоснование:**
1. Скриптовая парадигма с простым синтаксисом и динамической типизацией позволяет писать код быстро
2. В Python самая большая экосистема для ML (scikit-learn, PyTorch, TensorFlow) - алгоритмы не нужно писать с нуля
3. Невысокая скорость выполнения программы (по сравнению с компилируемыми языками) не критична, тк по тз прогноз обновляется 1 раз в сутки
4. Простой синтаксис и динамическая типизация помогают быстро менять и тестировать разные алгоритмы

---

## Задача 3

| | |
|---|---|
| **Парадигма** | Реактивное программирование |
| **Язык программирования** | TypeScript (React) |

**Обоснование:**
1. Реактивное программирование (React) автоматически обвновляет только те виджеты, где изменились данные, не трогая все остальное > обеспечивает мгновенную реакцию экрана
2. Реактивный подход одинаково легко обрабатывает данные из WebSocket, REST API и локальных событий как единый поток
3. Выбран TypeScript, а не JavaScript, так как строгая типизация позволяет избежать лишние ошибки и упрощает написание тестов

---

## Задача 4

| | |
|---|---|
| **Парадигма** | Императивная |
| **Язык программирования** | C |

**Обоснование:**
1. Императивная парадигма дает минимальный и компактный код без лишних надстроек
2. C компилируется в чистый машинный код, расходует мало энергии и не тратит ресурсы впустую
3. Позволяет напрямую работать с регистрами GPIO, ADC и UART.
4. У C нет сборщика мусора, поэтому время отклика строго детерминировано
5. Компиляторы C есть под любой микроконтроллер, код легко перенести на другую платформу
6. Выбран C, а не C++, тк классы, шаблоны и исключения забирают много памяти и не требуются по тз > программа менее предсказуемой по времени, а это критично для плат с 32 КБ
