# Лексический анализатор (токенизатор)

## Описание

Программа выполняет лексический анализ исходного кода и разбивает его на последовательность токенов

### Распознаваемые токены

| Тип      | Описание                                                         |
|----------|------------------------------------------------------------------|
| `IDENT`  | Идентификаторы (буквы, цифры, `_`, не начинаются с цифры)       |
| `KEYWORD`| Ключевые слова: `if`, `else`, `while`, `return`, `for`, `def`   |
| `INT`    | Целые литералы                                                   |
| `FLOAT`  | Вещественные литералы                                            |
| `STRING` | Строковые литералы в двойных кавычках                            |
| `OP`     | Операторы: `+ - * / = < > == <= >=`                             |
| `SEP`    | Разделители: `( ) { } , ;`                                      |

Пробелы, табуляция и комментарии (от `#` до конца строки) пропускаются

## Запуск программы

```bash
python tokenizer/main.py <путь_к_файлу>
```

### Пример

Создайте файл `input.txt`:

```
x = y * 2 + z * 3
```

Запустите:

```bash
python tokenizer/main.py input.txt
```

Вывод:

```
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```

## Ошибки

При обнаружении недопустимого символа программа выводит сообщение об ошибке и завершается с ненулевым кодом:

```
input.txt:1:3: lexical: unexpected character '@'
```
