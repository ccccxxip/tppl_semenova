# Стековая машина 
Программа на Python вычисляет выражение в постфиксной нотации и показывает состояние стека на каждом шаге

## Требования

- Python 3.8 или новее
- Для тестов: `pytest` и `pytest-cov`

## Как запустить

Из папки `postfix_notation`:

```
python main.py "3 0 4 ~ 2 ~"
```

Выражение можно передать одной строкой в кавычках или отдельными аргументами:

```
python main.py "2 3 +"
python main.py 2 3 +
```

**Выражение с `*` и `~` обязательно брать в кавычки.** Без них командная строка сама заменит `*` на список файлов, а `~` на путь к домашней папке, и выражение сломается. Если кавычки забыть, программа не упадет, а подскажет, что делать

Справка: `python main.py --help`

## Что умеет программа

- Операции `+`, `-`, `*`, `/` и специальный оператор `~`
- Целые и дробные числа, в том числе отрицательные (`5`, `-3`, `2.5`)
- Операнды и операторы разделяются пробелами
- Печатает стек после каждого шага
- Итог выводит в формате `выражение = результат`

## Оператор `~`

Достает из стека два операнда `x` и `y`:

- Если **оба не равны 0**, кладет в стек `|x - y|`
- Если **хотя бы один равен 0**, суммирует **все значения**: и достанные операнды, и те, что остались в стеке. Сумму возводит в квадрат и кладет в стек


## Вывод ошибок

Ошибки выводятся в поток ошибок, код завершения 1.

| Ситуация | Сообщение |
|----------|-----------|
| Выражение не передано | Справка по использованию |
| Деление на ноль | `шаг 3: деление на ноль (4 / 0)` |
| Оператору не хватает операндов | `шаг 2: для '+' нужно два значения, а в стеке их 1: [5]` |
| В конце в стеке больше одного значения | `в стеке осталось не одно значение, а 2: [1, 2]. не хватает операторов` |
| Неизвестный токен | `неизвестный токен 'abc'` и подсказка про кавычки |
| Слишком большое число | `супер большое число` |

Дробные результаты выводятся аккуратно: `0.3` а не `0.30000000000000004`, `6 / 2` = `3`, а не `3.0`.
